TV 자동 연동

토큰을 한 번 저장해 두면, 영상을 등록·삭제하거나 운동을 완료 체크할 때마다 저장소의 videos.json이 자동으로 갱신돼요. TV 화면에 영상 목록이 나타나고, 운동 기록(스트릭)도 이 저장소를 통해 함께 보관돼요.
1) GitHub 토큰 만들기 페이지에서 Repository access는 Only select repositories → hometrainer, Permissions → Contents는 Read and write로 만들어요.
2) 만든 토큰(github_pat_로 시작)을 아래에 붙여넣고 저장해요. 토큰은 이 기기 브라우저에만 저장돼요.
※ 기기마다 가진 목록이 서로 다르면 자동으로 합쳐지지 않아요. 최신 목록을 가진 기기에서 지금 TV 목록 갱신을 누른 뒤, 다른 기기에서 지금 불러오기를 눌러 맞춰주세요 (불러오면 이 기기의 기존 목록은 덮어써져요).

인스타그램은 새 탭에서 열었어요. 다 보셨으면 아래에서 완료 체크해주세요.
